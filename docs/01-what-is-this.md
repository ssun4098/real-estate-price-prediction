# 1. 무엇을 하는 프로그램인가

## 한 문장 요약

> 땅(필지)을 고르면, 그 땅의 정보와 주변 사례를 **자동으로 모아서**, 그 땅에 건물을 지어 팔면 **돈이 남는지(사업성)** 계산해 주는 웹 프로그램입니다.

부동산 개발사업을 검토하는 사람이 엑셀과 여러 정부 사이트를 오가며 하던 일을 한 화면에서 하게 해 줍니다.

## 사용자가 하는 일

```
① 주소를 검색한다  →  ② 지도에서 필지를 고른다  →  ③ 조건(층수·분양가 등)을 입력한다
                                                              │
        ⑥ 결과를 저장한다  ←  ⑤ 수지분석표를 본다  ←  ④ "분석" 버튼
```

화면은 크게 두 부분입니다.

- **기본조사:** 선택한 땅의 필지 정보, 규제(용도지역 등), 주변 시설, 개발 규모
- **수지분석:** 땅값 + 공사비 + 기타 비용 vs. 분양 수입 → 이익이 얼마인지

## 프로그램이 해 주는 일

| 일 | 설명 | 정보 출처 |
|---|---|---|
| 필지·지도·규제 조회 | 지번의 면적, 용도지역, 공시지가, 경계 | 브이월드 (국토 공간정보) |
| 주소 검색 | 도로명주소 → 좌표 | 주소기반산업지원서비스, 브이월드 |
| 땅 실거래 사례 | 주변에서 비슷한 땅이 얼마에 팔렸나 | 공공데이터포털 (국토교통부) |
| 분양 사례 | 주변 신축 아파트 분양가 | 공공데이터포털 (청약홈) |
| 사업성 계산 | 비용·수입·현금흐름·이익 | **이 프로젝트의 계산 엔진** |
| 결과 저장·비교 | 이전에 저장한 분석과 비교 | **이 프로젝트의 데이터베이스** |

## 중요한 원칙 세 가지

1. **없는 값을 채워 넣지 않습니다.** 자료를 못 가져오면 "산정 보류"라고 표시하지 숫자를 지어내지 않습니다.
2. **계산은 서버가 다시 합니다.** 화면에서 보낸 합계를 믿지 않고, 저장할 때 서버가 처음부터 다시 계산합니다.
3. **열쇠(API 키)는 절대 밖으로 나가지 않습니다.** 정부 사이트 이용 권한을 증명하는 비밀번호(키)는 서버 안에서만 쓰이고, 화면·저장 파일·응답에는 섞이지 않게 막아 둡니다.

## 현재 상태 (2026-10 기준)

- 화면(프런트엔드)과 계산 엔진은 완성되어 있습니다.
- 이번 리팩토링으로 서버를 **FastAPI + MySQL(데이터베이스)** 구조로 정리했습니다. 저장 방식이 "내 PC의 파일"에서 "데이터베이스"로 바뀌었습니다.
- **학습 모델(AI 예측)은 아직 없습니다.** 나중에 끼워 넣을 자리를 미리 만들어 두었습니다. (→ [5장](05-glossary.md))
