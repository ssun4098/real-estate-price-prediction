This directory contains the ES modules of **html-to-image 1.11.13**, downloaded
from the official npm package (`https://registry.npmjs.org/html-to-image/-/html-to-image-1.11.13.tgz`).
The MIT license is retained in `LICENSE`.

Only module filenames/import specifiers were normalized from `.js` / extensionless
imports to `.mjs`; references to absent source maps were removed. Library logic
is unchanged. These local ES modules keep the existing Data prebuilt authoring
workflow without changing dependencies or protected runtime files.
